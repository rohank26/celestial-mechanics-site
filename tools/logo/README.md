# Logo generator

The Celestial Mechanics crest and wordmark (`public/brand/cm-crest.svg`, `public/brand/cm-wordmark.svg`) are generated by `build_cm.py`, with all lettering converted to outlines. It reuses the frame, plaque, scrollwork and gradients of the Grand Orrery logos, from `build.py` and `build2.py` (copied from the Grand Orrery repository).

See [docs/EDITING.md § Logos](../../docs/EDITING.md#logos) to regenerate. Fonts (all SIL Open Font Licence): Cinzel, Cinzel Decorative, Pinyon Script.
